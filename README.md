# Black Dealer Network Website

This package contains the complete static website for Black Dealer Network.

## Files
- `index.html` - Full website
- `assets/bdn-logo.png` - BDN logo used in navbar, hero, and footer
- `assets/hero-car.png` - Car image used in the hero section
- `assets/favicon.png` - Browser favicon

## Deploy to Cloudflare Pages
1. Upload this folder to GitHub.
2. In Cloudflare Pages, connect the GitHub repository.
3. Framework preset: None
4. Build command: leave blank
5. Build output directory: leave blank or `/`
6. Deploy.
